System Architecture

Tech Stack

  • Backend: FastAPI, Python 3.10+
  • Machine Learning: Scikit-Learn, Optuna, XGBoost, LightGBM, SHAP
  • Frontend: HTML5, CSS3 (Glassmorphism), Vanilla JS, GSAP

Pipeline Summary

  1. Data Ingestion: Reads training & validation datasets.
  2. Preprocessing: Handles missing weights, parses dates, applies Target Encoding.
  3. Feature Engineering: Haversine distances, interaction terms, cyclical encodings.
  4. Model Selection: 5-Fold CV across 7 models. Picks lowest RMSE.
  5. Hyperparameter Tuning: Optuna optimization (TPE Sampler).
  6. Serving: Deployed via FastAPI REST endpoints.
